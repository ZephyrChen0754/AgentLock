# AgentLock 兼容性记录

AgentLock 让任务留在当前 Windows 桌面，遮住物理屏幕并限制普通实体键鼠。截图和输入是否正常取决于 Agent 的具体实现；同一应用升级或更换设备后也应重新检查。

## 验证自己的 Agent

1. 先运行内置兼容性检查，再在不启用保护时完成一次正常任务。
2. 开启保护，用该 Agent 原来的方式截图、点击、滚动、输入，并确认物理屏幕被遮住、普通实体键鼠受限。
3. 按 F12，输入保护密码恢复操作，检查目标窗口焦点与任务状态。

可用 [离线实测页面](Agent实测页面.html) 与 [任务文本](给Agent的实测任务.txt) 留存两张变化时钟截图、三次点击和指定文字结果。不要用读取 HTML、DOM 或后台脚本代替本来要验证的桌面操作。详细项目见 [验收清单](验收清单.md)。

## 兼容性边界

- 常规解锁由实体 F12 呼出密码框，需保护密码；忘密恢复须完成本人 Windows 登录后重设。认证期间合成输入暂时阻断，取消返回保护后恢复放行。
- 本机已反馈保护中 Ctrl+Alt+Del 无响应，不可依赖它手动恢复。0.1.5 使用 F12 → “忘记密码” → 程序请求锁屏 → 本人 Windows 登录 → 自动重设；本机真实登录及自动重设集成已通过，其他设备仍需确认。
- 普通取消保持保护；取消重设保留旧密码并撤销一次性资格。系统实际锁定后再实际解锁才授权，查询未知、仅请求获准或未核实系统通知不能授权；再次恢复需要新的原生登录。
- 密码框失焦时有 8 秒实体点击宽限；点击须实际命中框内控件且无他窗捕获，键盘仍要求密码框前台。无法恢复时尝试 Windows 原生锁屏。
- 注入标记不是可信 Agent 身份。管理员、同权限软件、安全桌面、Raw Input / DirectInput 等特殊路径不属于完整防护承诺。
- 触屏 / 笔检测到时拒绝开启或尝试原生锁屏降级；其他设备、多屏与热插拔需单独验证。
- 截图黑屏、出现遮罩或停帧时，应记录该应用 / 版本 / 采集方式的不兼容，不把别的截图工具通过当作替代证据。
- 普通应用与 Windows 原生锁屏的安全边界不同；程序仍会在可检测故障时自动尝试锁屏，实际结果须验证。真正锁定可能暂停 GUI Agent，强制终止到监控反应之间可能有短暂间隙。

健康探针正常由钩子吞掉。钩子故障时可能出现细小光标位移；健康探针不点击、不滚动。内置诊断另在自有面板验证合成点击与文字。
