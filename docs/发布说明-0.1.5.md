# AgentLock 0.1.5

本版新增本人 Windows 登录后的忘密恢复，品牌和界面沿用 0.1.4。F12、输入策略、密码哈希及既有故障锁屏机制保持原有范围。

## 新流程

**F12 → 忘记密码 → 程序请求 Windows 锁屏 → 本人 Windows 登录 → 自动重新设置保护密码。**

使用自己已配置的 Windows Hello、PIN 或系统登录密码完成登录。Windows 处理原生认证；AgentLock 不接收 Windows 凭证，只核对当前会话的实际锁定 / 解锁状态。未保护时也可从“设置保护密码”的验证框发起恢复。

- 普通密码框取消保持保护，不触发忘密恢复。
- 确认实际锁定、随后实际解锁后，自动显示重设窗口，授予一次重设资格。
- 重设保存后使用新密码；取消 / 关闭重设保留旧密码并作废资格。再次恢复需要新的原生登录。
- 锁屏请求被接受、未核实的系统通知或查询未知均不能当作完成认证；锁屏期间不授予重设资格。

本机保护中 Ctrl+Alt+Del 无响应，不能依赖它恢复；新增按钮由程序请求锁屏。自动故障锁屏仍保留，实际是否锁定须确认。进入系统锁屏后 GUI Agent 可能暂停，返回后检查任务与焦点。

## 实现与验证范围

输入策略、F12、密码哈希与故障锁屏机制保持原有范围。原生会话通知只触发重新查询，控制流程使用当前会话的新鲜状态；实际锁定再解锁才消费一次恢复资格，普通取消不授权。查询失败或异常状态保持拒绝授权。
