# AgentLock 验收清单

用于确认你的 Agent、设备与日常任务是否适合开启保护。0.1.5 新增本人 Windows 登录后的忘密恢复；44 项逻辑测试，以及本机真实锁屏 / 本人登录、自动重设和新密码生效集成检查已通过。恢复集成使用独立临时保护凭证，不重新验证实体 F12 或所有设备。内置检查和自动测试不能替代 Agent 自身的截图与输入验证。

## 准备

保存工作，确认知道 Windows 原生登录方式。记录 Windows、AgentLock、Agent 版本、屏幕布局 / 缩放与输入设备；先在不启用保护时完成一次正常任务，再短时间测试保护和解锁。

可使用 [离线实测页面](Agent实测页面.html) 和 [任务文本](给Agent的实测任务.txt)：页面从计数 0、空输入框开始，正确结果为两次变化时钟截图、计数 3、输入 `AgentLock 测试通过`。保持 Agent 平时的桌面截图 / 输入方式，不改用 DOM 或后台脚本；不要向 Agent 提供保护密码。

## 核对项目

| 项目 | 操作 | 通过条件 |
| --- | --- | --- |
| 原桌面 | 开启保护 | 原登录会话、窗口与任务保留，不切换用户或虚拟机 |
| 物理屏幕 | 查看所有显示器 | 遮罩覆盖全部物理屏幕，不露出任务内容或通知 |
| 实时截图 | Agent 连续截图变化窗口 | 至少两张内容 / 秒数不同的原桌面截图，无黑屏、遮罩或停帧 |
| Agent 操作 | 点击、滚动、切换窗口，输入英文 / 中文及快捷键 | 目标应用正确响应，输入不落入密码框或其他窗口；截图可见变化 |
| 实体限制 | 人移动、点击、滚轮、敲字及 Alt+Tab | 原桌面不受普通实体动作操控，Agent 保持任务进展；逐一记录触摸板 / 蓝牙 / USB 路径 |
| F12 与密码 | 松开所有键，F12 呼出，试错误密码、正确密码与取消 | F12 不直接解锁；错误 / 取消保持保护，正确密码恢复；连发 / 抬起不重复呼出 |
| 认证焦点 | 可见密码框失焦时在 8 秒内点击框内 | 实际命中框内控件可取得焦点，键盘随后只输入密码框；框外 / 覆盖 / 他窗捕获不放行 |
| 限流与持键 | 连续错误后重开；按住键 / 鼠标按钮尝试开启；认证中持键后取消再释放 | 未到期等待保留；持键拒绝开启；配对释放不造成卡键，新实体按下仍受限 |
| 独立运行 | 断网或结束手机远控 | 本机保护不依赖持续远控；任务进展按自身网络需求判断 |
| 多屏 | 不同 DPI、竖屏；保护与认证期间分别热插拔 | 覆盖及时更新，认证框可见；记录截图坐标 / 尺寸变化 |
| 长任务 | 先至少 30 分钟；计划 24 小时使用时补一次 24 小时 | 任务持续进展，遮罩 / 输入保护不失效，资源与睡眠状态可接受 |
| 忘记密码 | F12 → “忘记密码” → 程序请求锁屏 → 本人 Windows 登录 | 确认实际进入系统锁屏；原生认证返回后自动打开重设窗；锁屏期间或状态未知不授权 |
| 重设与取消 | 设置新密码；另一次恢复时取消重设，再尝试恢复 | 新密码生效，资格只用一次；取消保留旧密码且资格作废；再次恢复必须完成新的原生锁解周期 |
| 普通取消与假通知 | 取消普通密码框；检查未实际锁定时的状态 | 取消保持保护，不发起忘密恢复；请求获准、未知查询或未核实通知不授予重设资格 |
| 故障恢复 | 记录自然出现的故障及自动处理 | 故障不继续显示健康；自动锁屏请求与实际锁屏分别确认，不把请求获准当成功 |

认证期间合成输入暂时阻断，取消返回保护后恢复放行。解锁前暂停当前 Agent 点击 / 输入动作，返回后确认目标窗口焦点。检测到持键时先松开再重试，不在“保护没有开启”状态离开。

## 边界与异常

- 正常密码入口是 F12。本机已反馈保护中 Ctrl+Alt+Del 无响应，不显示安全界面；不要把它当作手动恢复或忘记密码后的到达路径。
- 忘记密码使用应用的“忘记密码”按钮，由程序请求 Windows 登录恢复。本机真实登录与自动弹出重设窗已有集成记录；重设取消的真人操作、其他设备及登录配置仍需验收，不能只用纯授权策略作为系统登录证据。
- Windows 安全界面、UAC、切换用户及管理员操作属于原生或高权限边界；不保证这些界面的可达性或 GUI Agent 连续工作。
- 触屏 / 笔尚不承诺支持；检测到时拒绝开启或尝试锁屏降级。特殊 HID、屏幕键盘、语音、Raw Input / DirectInput 单独验证。
- 合成输入标记不等于可信 Agent 身份，其他软件的合成输入也可能获准。
- 睡眠、休眠、重启或断电不保证任务继续；不保存 Windows 密码用于自动登录。
- 故障时程序仍自动尝试原生锁屏，实际故障路径待验证；请确认屏幕确实锁定后再离开。请求被系统接受不等于已锁定；强制终止与监控反应之间可能有短暂间隙。
- 健康探针不点击、不滚轮；输入钩子故障时可能有细小光标位移。不要在含敏感资料的桌面主动破坏保护来测试。

## 留存结果

分别记录物理屏幕观察、Agent 自身截图和操作结果，附上版本、设备、时间与最长运行时长。去除密码、账户及个人内容后再分享；标明未测项目。

指定 Agent 和设备完成核心截图、操作、实体限制与密码恢复后，才记录为基本兼容；多屏、特殊设备和长期使用补对应测试。异常未验须注明，不将本机基础诊断或一次成功推广为所有配置通过。结果模板见 [兼容性记录](兼容性记录.md)，恢复说明见 [安装与使用](安装与使用.md)。
